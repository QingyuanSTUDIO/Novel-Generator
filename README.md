# Novel Generator

Vue 3 + TypeScript + Vite 的小说创作工作台初版。

## 启动

```bash
npm install
npm run desktop:dev
```

`npm run desktop:dev` 会启动独立桌面窗口，窗口关闭后本地服务会自动退出。也可以直接双击项目根目录的 `start.bat`，它会构建并启动桌面版。

本项目只提供 Electron 独立桌面窗口入口。开发时使用 `npm run desktop:dev`，发布预览使用 `npm run desktop`。

## 当前能力

- 章节写作：章节切换、正文编辑、自动保存、专注写作模式。
- 世界书、角色卡、道具卡、技能卡、大纲、世界引擎、文风规则：条目新建、编辑、删除和本地持久化。
- 世界书、角色卡、道具卡、技能卡支持自定义折叠栏，条目可以拖放到不同分组。
- 角色卡关联：角色可以通过加号关联持有道具和持有技能，点击标签查看对应卡片详情。
- 角色卡新建使用角色模板，包含角色身份枚举（主角 / 配角 / 路人）、角色信息、背包和技能关联。
- 当前作品菜单支持删除当前作品；删除前会弹窗确认，并保留全局 API 设置。
- 上下文编排：提示块启用 / 禁用、顺序调整、token 预算预览。
- API 配置：协议枚举、按配置地址真实拉取模型、下拉选择、连接测试。API 设置从右上角的设置按钮打开独立面板；每个预设可分别保存上下文长度、最大回复长度、对话记忆预算，以及可选的温度、Top P、频率惩罚和存在惩罚。
- 生成候选正文：通过所选 API 请求真实模型，支持流式输出；完整生成后由作者采纳。
- 上下文与用量：正文和 Agent 显示本地估算的输入占比与输入余量，点击圆环查看预算和接口返回的输入、输出、缓存读取及缓存写入 Tokens。未返回的统计保持未知。

作品数据和全局设置会保存到 Electron 的应用数据目录；本地存储不可用时才使用窗口本地缓存作为兜底。新建作品只替换作品资料，不会覆盖 API、模型列表和 Agent 设置。

上下文长度是作者根据模型实际容量填写的本地预算，不会扩大服务端限制。发送前预留最大回复和 5% 安全余量，按 Token 估算裁剪最近的完整对话轮次；完整聊天记录仍然保存。协议、检索资料和本次需求超出预算时会提示调整，不会截断 JSON 或锁定规则。采样参数留空使用服务端默认值；Anthropic 不发送不支持的两项惩罚参数。缓存统计来自服务端 `usage`，流式统计开关只请求用量信息，不控制服务端缓存。

API 设置的“获取模型上限”只向当前配置的服务器查询所选模型的元数据。服务器提供容量时自动填入上下文预算；同时返回较小的输入上限时，取较小值作为保守预算；只提供输入上限时，会明确标注并将其作为保守预算，不将输入、输出上限相加。未提供容量时保留原值。不会提高作者的回复预算，也不会改变对话记忆预算或连接验证状态；必要时只下调回复预算以保留输入空间。

获取模型由本地 Node 服务转发，桌面窗口不会直接请求中转站：

- 桌面窗口通过本机 Node 服务请求 `POST /api/proxy/models`，因此不会受到中转站跨域限制或系统代理扩展的影响。
- 本地服务会请求当前预设的 `Base URL/models`；如果地址没有以 `/v1` 结尾，也会尝试 `Base URL/v1/models`。
- API 预设里的“使用代理”是可选的上游出口代理。关闭时 Node 直接访问中转站；开启后按“代理地址”和“代理端口”通过 HTTP 代理（例如 Clash 的 `127.0.0.1:7890`）访问中转站。这一项只影响模型请求的上游出口。
- 可用 `GET http://127.0.0.1:3100/api/health` 检查本地代理是否启动。

## 代码结构

```text
src/
  App.vue                 跨页面状态和业务动作
  components/
    SidebarNav.vue        作品模块导航
    ResourceCollectionView.vue 资料卡列表、折叠栏和拖放
    TopBar.vue            顶部状态栏
  data/seed.ts             初始数据和本地存储迁移
  types.ts                 共享类型
  styles.css              全局布局与主题样式
  main.ts                 应用入口
electron/
  main.mjs                独立桌面窗口入口
```

模型请求由共享 API client 和本地 Node 服务处理，正文、Agent、段落改写和世界引擎共用所选预设的生成参数。
